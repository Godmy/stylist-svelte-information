# stylist-svelte-information

Source module extracted from stylist-svelte (afb6258628fba28b6a9bfec6b959f1ea9dd3e4ea).

Domains: `list`, `tree`, `table`, `chart`, `image`, `audio`, `video`, `notification`, `content`.

`content` owns the shared article document, block reader and block editor. Image
dimensions and attribution belong to `image`; site routes, publishing, storage,
SEO and product relationships remain in application adapters.

Part of the shared stylist-svelte package. Development, indexing and sandbox integration are managed by the umbrella repository.
